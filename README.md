# Planets

## Для поддержки дат до н. э.:
1. Установить библиотеку Skyfield. Для этого необходимо открыть командную строку и ввести команду: ```python -m pip install skyfield```.
2. Скачать код с ветки (версии проекта) "develop".
   - Найти кнопку для выбора веток. Она расположена первой слева в одном ряду с кнопкой "Code", которая используется для скачивания zip-архива кода. Сейчас на кнопке выбора веток можно увидеть текст "main".
   - Нажать на кнопку. Появится выпадающий список, где напротив опции "main" будет отображена галочка. Чуть ниже будет опция "develop". Необходимо выбрать ее.
   - Теперь на кнопке выбора веток можно увидеть текст "develop". Скачиваем и запускаем код как обычно.
