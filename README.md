# Planets

Снизу представлен график тестирования. Отклонение указано в градусах. Отрицательные года обозначают года до н. э. В качестве отклонения представлено максимальное значение за 100 лет. Например, для точки с датой 500 лет н. э. будет указано максимальное отклонение в промежутке с 500 по 600 год н. э.
